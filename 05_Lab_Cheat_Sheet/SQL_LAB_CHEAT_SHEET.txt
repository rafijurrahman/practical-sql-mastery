১. কুয়েরি লেখার ক্রম বনাম ইঞ্জিনের এক্সিকিউশন অর্ডার
--------------------------------------------------------------------------------
কোডিং লেখার ক্রম:  SELECT -> FROM -> WHERE -> GROUP BY -> HAVING -> ORDER BY -> LIMIT
ইঞ্জিনের রান ক্রম:
  1. FROM & JOIN     : ডেটার মূল টেবিল ও সম্পর্ক নির্ধারণ।
  2. WHERE           : প্রতিটি একক সারি ফিল্টার (এখানে এগ্রিগেট চলে না)।
  3. GROUP BY        : ক্যাটাগরি ভিত্তিক গ্রুপে ভাগ।
  4. HAVING          : এগ্রিগেট স্কোরের ওপর শর্ত পরীক্ষা।
  5. SELECT          : নির্দিষ্ট কলাম ও এক্সপ্রেশন তৈরি।
  6. DISTINCT        : ডুপ্লিকেট সারি ছাঁটাই।
  7. ORDER BY        : সারি সাজানো (এখানে SELECT-এর অ্যালিয়াস কাজ করে)।
  8. LIMIT / OFFSET  : কাঙ্ক্ষিত নির্দিষ্ট সংখ্যক সারি রিটার্ন করা।

২. SQLite 3.30 ডেটা টাইপ ও কনস্ট্রেইন্ট
--------------------------------------------------------------------------------
  INTEGER   : পূর্ণসংখ্যা (Primary Key হলে স্বয়ংক্রিয় Auto Increment)।
  REAL      : দশমিক ভগ্নাংশ সংখ্যা (1250.50)।
  TEXT      : যেকোনো স্ট্রিং এবং তারিখ ('YYYY-MM-DD' ISO ফরম্যাটে)।
  NULL      : অজানা বা অনুপস্থিত তথ্য। (মনে রাখবেন: 0 বা '' ফাঁকা স্ট্রিং NULL নয়!)

৩. ফিল্টারিং ও লজিক্যাল অপারেটর (WHERE)
--------------------------------------------------------------------------------
  =, <>, != : মান সমান বা অসমান কি না পরীক্ষা।
  BETWEEN   : রেঞ্জ ফিল্টার (উভয় প্রান্ত Inclusive)। উদা: price BETWEEN 500 AND 1000
  IN (...)  : তালিকার যেকোনো মানের সাথে মিল। উদা: city IN ('Barishal', 'Bhola')
  LIKE      : প্যাটার্ন ম্যাচিং (% = বহু অক্ষর, _ = নির্দিষ্ট ১টি অক্ষর)
  IS NULL   : নাল পরীক্ষা (কখনও = NULL লিখবেন না!)
  AND / OR  : লজিক্যাল একত্রীকরণ। ব্র্যাকেট () দিয়ে অগ্রাধিকার নিশ্চিত করুন।

৪. এগ্রিগেট ফাংশন ও গ্রুピング (GROUP BY & HAVING)
--------------------------------------------------------------------------------
  COUNT(*)    : নাল সহ সমস্ত সারি গুনে।
  COUNT(col)  : শুধুমাত্র ঐ কলামের অ-নাল সারি গুনে।
  SUM, AVG, MIN, MAX : গাণিতিক সমষ্টি ও পরিসংখ্যান।
  নিয়ম: SELECT-এ কোনো নন-এগ্রিগেট কলাম থাকলে তা অবশ্যই GROUP BY-তে থাকতে হবে।
  HAVING: এগ্রিগেট মানের ওপর শর্ত দিতে (উদা: HAVING SUM(amount) > 3000)।

৫. শর্তযুক্ত লজিক ও ডেটা ক্লিনিং (CASE, COALESCE & NULLIF)
--------------------------------------------------------------------------------
  CASE:
    CASE 
      WHEN total >= 4000 THEN 'Platinum'
      WHEN total >= 2000 THEN 'Gold'
      ELSE 'Silver'
    END AS tier
  COALESCE(val, 'Default') : প্রথম অ-নাল মান রিটার্ন করে।
  NULLIF(a, 0)             : বিভাজক শূন্য হলে NULL রিটার্ন করে জিরো-ডিভিশন প্রতিরোধ করে।
  CAST(col AS REAL)        : পূর্ণসংখ্যাকে দশমিকে রূপান্তর করে (বা col * 1.0)।

৬. রিলেশনাল জয়েন ম্যাট্রিক্স (Joins)
--------------------------------------------------------------------------------
  INNER JOIN : উভয় টেবিলে মিল থাকা সারি। (FROM c JOIN o ON c.id = o.c_id)
  LEFT JOIN  : বাম টেবিলের সমস্ত সারি অক্ষত রেখে ডানের মিল আনে।
  Anti Join  : বাম টেবিলে আছে কিন্তু ডানে কোনো অর্ডার নেই:
               LEFT JOIN o ON c.id = o.c_id WHERE o.id IS NULL
  SELF JOIN  : একই টেবিলকে কর্মী ও সুপারভাইজার হিসেবে ডাকা:
               FROM emp e LEFT JOIN emp m ON e.manager_id = m.employee_id

৭. সেট অপারেটর (UNION, INTERSECT, EXCEPT)
--------------------------------------------------------------------------------
  UNION     : উভয় তালিকা একত্র করে ডুপ্লিকেট বাদ দেয়।
  UNION ALL : সমস্ত সারি জোড়া লাগায় (ডুপ্লিকেট রাখে, অনেক দ্রুত)।
  INTERSECT : কেবল উভয় তালিকার সাধারণ রেকর্ড আনে।
  EXCEPT    : প্রথম তালিকায় আছে কিন্তু দ্বিতীয় তালিকায় নেই এমন রেকর্ড আনে।

৮. স্ট্রিং ও টেক্সট ফাংশন
--------------------------------------------------------------------------------
  UPPER(str) / LOWER(str)    : অক্ষরের কেসিং পরিবর্তন।
  LENGTH(str)                : অক্ষরের মোট সংখ্যা।
  TRIM(str)                  : সামনে-পেছনের বাড়তি স্পেস ছাঁটাই।
  SUBSTR(str, start, len)    : সাবস্ট্রিং কাটা (ইনডেক্স ১ থেকে শুরু)।
  str1 || ' ' || str2        : স্ট্রিং কনক্যাটেনেশন বা জোড়া লাগানো।

৯. তারিখ ও সময় ফাংশন (Date & Time)
--------------------------------------------------------------------------------
  date('now')                             : বর্তমান দিনের তারিখ ('YYYY-MM-DD')
  date(order_date, '+30 days')            : ৩০ দিন পরের ডিউ ডেট
  CAST(julianday(d2) - julianday(d1) AS INT) : দুই তারিখের মধ্যবর্তী দিনের সংখ্যা
  strftime('%Y-%m', order_date)           : মাস-সাল ফরম্যাট (মাসিক সেলস গ্রুপিং)

১০. সাবকুয়েরি ও CTE (Common Table Expression)
--------------------------------------------------------------------------------
  EXISTS:
    SELECT * FROM customers c
    WHERE EXISTS (SELECT 1 FROM orders o WHERE o.customer_id = c.customer_id);

  Chained CTE:
    WITH spend_calc AS (
      SELECT customer_id, SUM(total_amount) AS total FROM orders GROUP BY customer_id
    )
    SELECT * FROM spend_calc WHERE total > 3000;

১১. উইন্ডো ফাংশন ও অ্যানালিটিক্যাল কুয়েরি
--------------------------------------------------------------------------------
  সিনট্যাক্স: FUNCTION() OVER (PARTITION BY col1 ORDER BY col2 [FRAME])
  ROW_NUMBER() : প্রতিটি সারির জন্য ১, ২, ৩ ক্রমিক নম্বর।
  DENSE_RANK() : টাই থাকলে একই র‍্যাংক দেয়, সংখ্যা স্কিপ করে না (১, ১, ২)।
  LAG(col, 1)  : পূর্ববর্তী সারির মান আনে (MoM Growth পরিমাপ)।
  Running Total: SUM(revenue) OVER (ORDER BY month_id)

১২. ল্যাবের শীর্ষ ৫টি কমন এরর ও তাৎক্ষণিক ফিক্স
--------------------------------------------------------------------------------
  ১. ভুল: WHERE SUM(amount) > 500  --> ফিক্স: HAVING SUM(amount) > 500 লিখুন।
  ২. ভুল: WHERE phone = NULL       --> ফিক্স: WHERE phone IS NULL লিখুন।
  ৩. ভুল: 3 / 5 = 0 (ভাগফল শূন্য) --> ফিক্স: 3 * 1.0 / 5 লিখুন।
  ৪. ভুল: ambiguous column name    --> ফিক্স: c.city, o.city টেবিল অ্যালিয়াস দিন।
  ৫. ভুল: কনক্যাটে পুরো লাইন NULL --> ফিক্স: COALESCE(col, '') ব্যবহার করুন।
